# YU｜諮商心理師 個人品牌網站｜第一版

這是一個不需要後端、不需要資料庫、可以直接在電腦開啟的靜態網站。

## 你會看到的頁面

1. index.html → 首頁
2. about.html → 關於我
3. articles.html → 心理文章
4. speaking.html → 講座與合作
5. contact.html → 聯絡我
6. style.css → 全站視覺
7. script.js → 手機版選單互動
8. images/ → 放照片、Logo、文章圖片

## 最簡單的開啟方式

直接雙擊 index.html。

它會在瀏覽器開啟網站。

## 如果你要修改文字

例如 contact.html 裡面的：

your-email@example.com

請改成你的實際專業信箱。

about.html 裡面的：
「請替換為你的正式學歷資料」
「請替換為你的正式工作／實習經歷」

也請改成正式內容。

## 如果要放自己的照片

1. 把照片放進 images 資料夾。
2. 例如命名為 profile.jpg。
3. 到 about.html 找到 profile-placeholder。
4. 之後可以把那個區塊替換成：

<img src="images/profile.jpg" alt="YU｜諮商心理師">

## 如果你要新增心理文章

第一版為了簡單，文章目前集中在 articles.html。

之後如果文章越來越多，可以改成：
articles/
  article-01.html
  article-02.html
  article-03.html

這部分我可以再幫你建立。

## 目前網站特色

- 奶油色＋淺藍色
- 柔和、清楚、專業
- 不使用植物元素
- 電腦版＋手機版
- 無外部套件依賴
- 不需要資料庫
- 不需要登入系統
